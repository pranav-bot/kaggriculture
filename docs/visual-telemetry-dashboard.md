# Kaggriculture Visual Telemetry Dashboard

A local, high-performance Streamlit dashboard designed to visually inspect and debug the internal decision-making of Kaggriculture agents across all 720 match turns.

The dashboard integrates offline telemetry logs (`telemetry.jsonl`) generated by [`tools/shadow_telemetry.py`](file:///Users/pranav/dev/kaggriculture/tools/shadow_telemetry.py) alongside official Kaggle replay files (`replays/*.json`), providing real-time 10x10 farm terrain visualization, Value Net divergence tracking, Beam Search rollout trees, and Kuhn-Munkres labor assignment matrices.

---

## Quickstart

### Launch the Dashboard
```bash
# Launch via the top-level app wrapper:
streamlit run app.py

# Or directly through the dashboard module:
streamlit run dashboard/app.py
```
Open your browser at **`http://localhost:8501`**.

## Core Capabilities & Diagnostic Panels

### 1. Master Turn-Scrubber & 10x10 Farm Terrain Grid
- **Turn Scrubber**: Interactive slider from Turn 0 to Turn 719, synchronized with Day (`turn // 24`) and Hour (`turn % 24`), with step controls (`-24h`, `-1h`, `+1h`, `+24h`) and milestone event anchors (Opening Book, NE Expansion, Handoff, Divergence Point, Liquidation).
- **10x10 Farm Grid**:
  - **Quadrants**: Clearly partitioned into NW (Base), NE ($1,000), SW ($2,000), and SE ($4,000).
  - **Tile States**:
    - `🔒 Locked`: Dark gray with padlock indicator.
    - `🌱 Soil`: Empty arable land available for planting or pasture expansion.
    - `🏚️ Shed`: Central storage facility (coords `(4,4)`, `(5,4)`, `(4,5)`, `(5,5)`) with hoverable inventory counts.
    - `🌿 Weed`: Invasive weed tiles flagged for clearing.
    - `🍓 Crops`: 🍓 Strawberry, 🍈 Melon, 🌾 Wheat, 🥕 Carrot, 🍅 Tomato with growth age, yield units, water status (`💧` vs `🥀`), and fertilizer sparkles (`✨`).
    - `🐄 Animals`: 🐄 Cow, 🐑 Sheep, 🪿 Goose with feed status (`🌾` vs `⚠️`), care status (`❤️` vs `💔`), and fertilizer ready (`💩`).
    - `🧑‍🌾 Workers`: Farmer (gold glowing avatar) and Farmhands (blue glowing badges `👷 Hand 0`, `👷 Hand 1`, ...).

### 2. Panel 1: Value Panel (IQL Predicted RTG vs Replay Cash)
- Compares the Implicit Q-Learning (IQL) Value Net's predicted Return-To-Go ($\hat{V}_t$) and predicted terminal cash ($\text{Cash}_t + \hat{V}_t$) against actual replay return-to-go ($\text{RTG}_t = \text{Cash}_{719} - \text{Cash}_t$).
- **Automated Divergence Point Detection ($T^*$)**: Automatically flags the exact turn where actual replay cash permanently diverges from the model's expectations, annotating the timeline with a diagnostic explanation (e.g., wholesale market saturation or delayed land monetization).

### 3. Panel 2: Search Panel (24-Step Beam Search Tree & Candidates)
- Displays the exact 24-step Beam Search candidate trajectories evaluated on that day:
  - **Rank 1 (Selected Winner)**: Winning sequence of 24 macro-actions, mathematical score, leaf evaluation, and holding penalty.
  - **Rank 2 & 3 (Pruned Candidates)**: Alternative strategic branches (e.g. premature market liquidation or aggressive expansion) with score deltas $\Delta S$ and holding penalty deductions.
  - **Interactive Tree-Graph**: Plotly tree visualization displaying the branching factor across the 24-hour cycle.
  - **Schedule Table**: Full hourly schedule mapping macro-actions to physical operations.

### 4. Panel 3: Labor Panel (Kuhn-Munkres Routing & Debugger)
- **Cost Matrix Heatmap ($N \times M$)**: Full interactive matrix displaying costs between all active workers (Farmer + Hands) and candidate targets (weeds, strawberries, wheat, pastures). Cells corresponding to the Hungarian algorithm's optimal bipartite matching are highlighted with green badges.
- **Strawberry vs. Weed Forensic Debugger**:
  - Addresses why a worker ignored a high-value Strawberry to dig a nearby weed:
    $$\Delta C = C(W, \text{Weed}) - C(W, \text{Strawberry}) < 0$$
  - Compares Manhattan travel distance, role specializations, and priority bonuses, explaining why the Hungarian algorithm assigned the worker to the weed to minimize global fleet travel cost.

## Generating Offline Shadow Telemetry

To generate a new `telemetry_<EPISODE_ID>.jsonl` log from an arbitrary Kaggle replay without modifying agent source code:

```bash
# Generate telemetry from replay and agent:
python tools/shadow_telemetry.py \
    --replay replays/my_agents/psro_leauge_pick/114793445.json \
    --agent submissions.hybrid_grandmaster_v2.main \
    --seat 0 \
    --out data/telemetry

# Copy or symlink to telemetry.jsonl for default loading:
cp data/telemetry/telemetry_114793445.jsonl telemetry.jsonl
```

The shadow injector intercepts internal subsystems via `unittest.mock.patch` without modifying agent source code:
- CFR Regret Table and policy distributions
- 24-step Beam Search candidates and IQL leaf evaluations
- Bayesian opponent intent distributions
- Kuhn-Munkres worker routing and cost matrices
- Claude DP Endgame solver safe sale quotas
